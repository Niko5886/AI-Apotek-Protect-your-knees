# securify — Data Security Hero

Full-screen hero section for a data-security SaaS landing page, built with
**React + TypeScript + Tailwind CSS** and a looping fullscreen background video.

Design generated from a [MotionSites](https://motionsites.ai/?prompt=securify-hero)
prompt (`securify-hero`) and implemented as a real Vite component.

## Features

- Looping fullscreen background video (`object-cover`)
- Floating pill-shaped navbar (logo + links + `get started` button)
- Large staggered typography (`protect` / `your` / `data`) in **Readex Pro**
- Three stat blocks with diagonal dividers (`+65k`, `+1.5b`, `+300k`)
- Pure black / white / neutral-900 palette
- Responsive: nav links and dividers hide on mobile; type scales via `vw` units

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite 5
- React 18 + TypeScript 5
- Tailwind CSS 3
